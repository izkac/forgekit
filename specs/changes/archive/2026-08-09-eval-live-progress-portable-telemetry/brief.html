Evaluation runner observability and privacy

Real model trials can take several minutes. The runner will keep its final plan on stdout while sending sanitized lifecycle messages and periodic heartbeats to stderr, so an operator can distinguish healthy work from a hang.

Forge artifact telemetry will identify its directory with a run-relative locator rather than exposing an absolute checkout path. Existing outcome and file-inventory data remains available.

Acceptance

  • Long fake Harbor runs show start, heartbeat, and terminal progress.
  • stdout remains one parseable JSON plan.
  • Structured run artifacts contain no checkout or run-root path.
