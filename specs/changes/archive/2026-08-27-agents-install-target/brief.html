Vendor-neutral .agents install target

TL;DR

Forge can currently only be installed per tool (Cursor, Claude Code, Codex, …). After this change you can also install it once into the shared .agents folder that a growing number of AI tools read — the same option OpenSpec ships. One copy serves every compatible tool, and a repo can carry the Forge skill for the whole team.

What you'll get

  • A new environment called Shared .agents (vendor-neutral) in the forgekit install picker. Picking it puts skills in ~/.agents/skills/, where compatible tools find them.
  • A new forge init --agents option that puts the Forge skill inside the project itself (.agents/skills/forge/), so anyone cloning the repo has Forge available in a compatible tool with no setup.
  • forge doctor tells you when the project copy is out of date and how to refresh it.

How it works

The shared target is skills only, deliberately. Slash-command menus and hooks are different in every tool, so those stay with the per-tool setups. In a tool that only knows the shared folder, you start Forge by asking for it by name ("use Forge") instead of a slash command — that invoke already works. You can pick the shared target together with the per-tool ones; each writes to its own place and they don't conflict.

What changes for you

  • forgekit install shows one more environment to tick.
  • forge init --agents is new; combine freely, e.g. forge init --agents --cursor.
  • Nothing changes for existing setups if you don't pick the new target.

Risks and open questions

  • How tools invoke skills from the shared folder varies by tool; we document "ask by name" as the common form, same caveat OpenSpec gives.
  • Codex reads both its own folder and .agents; if you use both installs, the copies are refreshed by the same commands, but a forgotten one can lag. forge doctor warns for the project copy.

Out of scope

  • No editing of AGENTS.md files.
  • No shared command files or hooks — per-tool setups remain the full-featured path.
  • Forgekit only manages its own folders under .agents/skills/; everything else there is left alone.
