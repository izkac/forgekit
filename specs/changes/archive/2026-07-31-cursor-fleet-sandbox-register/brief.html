Cursor sessions in Forge fleet

TL;DR

Forge sessions started from Cursor never showed up in forge fleet, because Cursor’s agent sandbox blocks writes to the shared fleet folder under your home directory. After this change, registration failures leave a local “try again later” stamp, reminder hooks and a new sync command recover them, Cursor chats bind as Cursor (not “unknown”), and project init actually wires the Cursor session-start hook.

What you'll get

  • Cursor Forge work appears in forge fleet list once registration can write (or after sync).
  • A clear warning when the sandbox blocked registration, with what to do.
  • forge fleet sync to re-register every session in the current project.
  • Cursor host binding so telemetry can attach conversation ids.
  • forge init --cursor creates/merges .cursor/hooks.json instead of only a snippet.

How it works

Saving a session still tries to mirror into the machine-wide fleet folder. If that write is permission-denied (typical under Cursor’s sandbox), Forge drops a small pending file next to the session. The next reminder/session-start that can write home, or an explicit sync, finishes registration and clears the pending file. Agents are also told to run forge with unrestricted shell permissions under Cursor so the first write often succeeds. 

flowchart LR
  A[forge new / phase] --> B{Write ~/.forgekit/fleet?}
  B -->|ok| C[Visible in forge fleet]
  B -->|permission denied| D[fleet-pending.json in project]
  D --> E[reminder or forge fleet sync]
  E --> C

What changes for you

  • New command: forge fleet sync in a project that has missing fleet rows.
  • Under Cursor, forge commands that create/update sessions should run unsandboxed (agent requests full permissions).
  • Re-run forge init --cursor (or merge hooks) so session-start reminders fire.

Risks and open questions

  • If Cursor hooks themselves are sandboxed the same way, pending may linger until you sync from a normal terminal — watch for that.
  • Merging hooks must not wipe other Cursor hooks; tests cover the merge path.

Out of scope

  • Moving the fleet registry into each project.
  • Full Cursor transcript metrics (binding only).
  • Changing Cursor’s sandbox product behaviour.
