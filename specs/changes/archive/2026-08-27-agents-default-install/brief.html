Shared .agents becomes the default install; the project copy is retired

Why now. We checked the current host documentation: Cursor reads skills natively from ~/.agents/skills/ and .agents/skills/, and for Codex CLI the shared .agents root is the canonical skills location (its old vendor path is deprecated). Only Claude Code still requires its own ~/.claude/skills/. So the shared root should be the default install, and the per-project copy added in 0.3.48 is redundant.

What changes for you

CommandBefore (0.3.48)After
forgekit install Shared .agents was the last picker entry, never pre-checked. Shared .agents is the first picker entry and pre-checked by default (you can still unselect it). Cursor/Codex stay selectable — their labels note they also read the shared root. New --shared shorthand.
forge init --agents copied the Forge skill into <project>/.agents/skills/forge/. --agents is gone — it errors with a pointer to forgekit install. Init also deletes a leftover forgekit-stamped project copy and reports the cleanup. Foreign files under .agents/ are never touched.
forge doctor Warned when the project copy was stale, suggesting forge init --agents. Warns that a stamped project copy is a legacy leftover and names the cleanup. Unstamped directories are ignored (not ours to judge).

Where skills live after this change

HostReads
Cursor~/.agents/skills/ (shared, default) — also ~/.cursor/skills/ if you keep the per-tool install
Codex CLI~/.agents/skills/ (its canonical location)
Claude Code~/.claude/skills/ only — keep the Claude target selected
One-time effect. If a project has a stamped .agents/skills/forge/ from 0.3.48 (possibly committed to git), the next forge init deletes it. The git diff makes that reviewable; nothing is lost — the same skill is served from ~/.agents/skills/.

Not changing

  • Claude Code wiring (commands, hooks, rules, skills) — untouched.
  • Per-project wiring (forge init --cursor/--claude/--codex) — commands, thin rules, and hooks land per target exactly as before.
  • forgekit update ownership rules — only stamped copies are ever rewritten.
