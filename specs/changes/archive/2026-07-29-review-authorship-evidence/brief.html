Review authorship is measured, not read

Operator brief · change review-authorship-evidence · pace thorough

TL;DR

  • Forge decides "was this review written by an independent reviewer, or by the agent reviewing its own work?" by reading the review file's wording — text written by the party being judged.
  • That rule was rewritten five times in one day and was wrong every time. Twice it was wrong at the gate that protects money and auth changes: once it blocked correct work, once it let through a session that said in plain English its reviewer had been declined.
  • This change stops asking the file and starts checking whether a reviewer actually ran — using the record Claude Code itself writes for every subagent, which cannot be faked without really dispatching one.
  • When that record is missing (Cursor, Codex, an old session), Forge behaves exactly as it does today. It never refuses work for lack of evidence.

What you'll get

TodayAfter
A review headed Reviewed: counts as a self-check, and forge phase done refuses a session that did get an independent review. The dispatch record says a reviewer ran. The verdict follows the record, whatever the file says.
A review saying "a reviewer was dispatched and declined by the operator" counted as independent and passed the money/auth gate. No dispatch record → self-check. If the operator stopped a dispatch, Forge says so and points at the proper waiver.
Rewording a heading changes your grade by up to 29 points. Wording changes nothing where evidence exists.

Claude Code writes a small file for every subagent it runs, including a description the coordinator types at dispatch time. Forge will prescribe that description (forge-review final <session-id>, printed by forge review-label final), which turns it into a reliable join between "a reviewer ran" and "this is the review". The session id is what makes the record this session's: one Claude Code conversation routinely hosts several Forge sessions, and without it a neighbour's reviewer is indistinguishable from your own. Measured: that field is present on 383 of 383 such records on this machine, and already matches all four review artifacts on the most recent real session.

Why not just have the agent record it? That was the first design. It was rejected on measurement: the equivalent existing command, forge evidence, is actually run for only about half of the files it exists to produce. A gate that depends on an agent remembering a command fails more often than the bug it replaces.

What changes for you

  • Nothing you have to do. No new command. The change is to a field the agent already fills in when dispatching a reviewer.
  • Scores may move for sessions where the wording and the reality disagreed — in both directions, toward the truth.
  • Cursor and Codex are unaffected, because they write no such records. They keep today's behaviour permanently.

Risks — stated plainly

  • This touches a gate that has been wrong five times. That is why pace is thorough: review after every task group, plus an independent review of the whole change. Not optional here.
  • Corrected after you approved this brief. It said a reviewer dispatched with the wrong description "falls back to wording… under-credits rather than over-credits". That was wrong. Measured afterwards: of 388 real dispatch records on this machine, 123 are reviews and 1 carries the prescribed label — so the original rule would have declared nearly every existing session self-reviewed and refused it at the gate. Forge now detects whether the convention is in use at all, and falls back to wording when it plainly isn't. One extra task (2.1b), 13 instead of 12.
  • Adoption is still gradual. The label is a convention, not an enforcement, so the wording path stays alive indefinitely.
  • Evidence expires. Transcripts are pruned within days; one-day-old sessions on this machine already have none. So the verdict is frozen when the session finishes rather than recomputed later.
  • Freezing can preserve a wrong verdict. If the evidence was misjoined, re-running won't correct it. Mitigated by recording how the verdict was reached alongside it.

Out of scope — deliberately

Five other known findings are not fixed here, and saying otherwise would repeat the mistake this change exists to correct:

  • Per-group review counts stay on wording. They're worth about 2 points; the final review is worth 29 plus the gate.
  • F18 / F19 — the known escapes in the wording rule survive, because that rule is still the fallback for hosts without records.
  • F11 (the word "contract" over-triggering), F13 (review depth barely affects the grade), F16, F14.
