Measure Forgekit without trusting Forgekit

In one sentence: add a Harbor-backed, containerized A/B harness that runs the same coding task with and without Forgekit and grades the result in a separate verifier.

What gets added

  • evals/ holds task fixtures, the Harbor runner, result normalization, and authoring guidance.
  • The baseline and Forge arms are staged from one canonical task, so their starting repository cannot drift.
  • The smoke task's verifier stays outside the agent image and emits numeric functional, regression, test-tamper, and shippable metrics.

What this does not claim

The first task only proves that the harness is wired correctly. It is not an effect-size result. Meaningful conclusions require a held-out corpus, repeated paired trials, and cost/time analysis.

How it is used

Install Harbor separately with uv tool install harbor, inspect a dry run locally, then invoke the runner with a selected agent and model. Run artifacts stay under ignored evals/.runs/.
