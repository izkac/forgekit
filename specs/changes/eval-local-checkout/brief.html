Evaluate this checkout without publishing it

Outcome: the Harbor runner can install an operator-built local Forgekit tarball in only the Forge arm and prove which exact bytes it installed.

Operator flow

  1. Run npm pack for the local Forgekit workspace.
  2. Pass the resulting archive with --forgekit-tarball.
  3. Inspect the recorded SHA-256 in the plan and trial manifests.

Safety boundary

The runner snapshots and hashes the archive, gives it a safe digest-derived name, verifies it inside Docker, disables install lifecycle scripts, and never sends it to the baseline or verifier. It does not publish or package arbitrary source directories.

Not claimed

The archive hash identifies Forgekit payload bytes, but transitive registry dependencies are not fully pinned. A local smoke proves packaging and Docker installation; provider-backed model evaluation remains a separate step.
