Let Forge finish the trial

Operator brief · change eval-unattended-timeouts

TL;DR

The first campaign run made Forge look worse at coding because three of its twelve trials never finished: one asked a person who isn't there, two ran out of a 20-minute clock while still reviewing. This change tells Forge there is no one to ask, and gives every campaign trial an hour — same cap for the plain agent, who will just finish early.

What you'll get

  • Forge's eval instructions say: this is unattended, don't wait, pick a default and keep going.
  • Campaign trials may run up to 60 minutes instead of 20, on both arms.
  • That timeout bump is a new episode version (1.1.0), so we don't mix it with the first run.
  • Reviews and tests stay. We are not thinning Forge to make it look cheaper.

How it works

Every eval already stamps a short "you are the Forge arm" note onto the task. That note will now also say there is no operator. The six campaign tasks will advertise a one-hour agent limit to Harbor. The next live campaign run is a new cohort; don't average it with the 1.0.0 numbers.

What changes for you

The next authorized campaign run will cost more wall-clock if Forge uses the extra time — up to about an hour per Forge trial in the worst case, instead of twenty minutes. Baseline should still finish in a few minutes. Use a new seed and treat results as a 1.1.0 cohort.

Risks and open questions

The Forge workflow skill still tells agents to confirm fuzzy design choices. If that voice wins over the eval note, we may still see a question-and-stop. We will look at that on the next run rather than rewriting the skill now.

Out of scope

  • No change to the Forge skill that humans use in the editor.
  • No change to hard-v2's 20-minute cap.
  • No rerun of the live cohort as part of this change — that stays a separate spend decision.
